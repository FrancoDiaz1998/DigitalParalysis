--- REQUERIMINETOS FUNCIONALES ---

📃 USUARIOS 📃
1- El sistema debe permitir crear usuarios
2- El sistema debe permitir dar de baja lógica a usuarios
3- El sistema debe permitir eliminar cuenta de usuario permanentemente
4- El sistema debe permitir modificar datos del usuario
5- El sistema debe permitir cambiar contraseña
6- El sistema debe permitir iniciar sesión
7- El sistema debe permitir cerrar sesión
8- El sistema debe permitir visualizar perfil del usuario
9- El sistema debe permitir al admin visualizar todos los usuarios

📃 OBRAS 📃
10- El sistema debe permitir crear una obra con su tipo la cual puede ser película, serie, documental,etc.
11- El sistema debe permitir eliminar una obra (película, serie, etc.)
12- El sistema debe permitir modificar una obra (película, serie, etc.)
10- El sistema debe permitir visualizar obras con su información (película, serie, etc.)
11- El sistema debe permitir buscar obras por su nombre
12- El sistema debe permitir filtrar obras por tipo (series,sagas,etc..)
13- El sistema debe permitir filtrar obras por año
14- El sistema debe permitir filtrar obras por género
15- El sistema debe permitir filtrar obras por temáticas
16- El sistema debe permitir filtrar obras por actores/directores
17- El sistema debe permitir filtrar obras por plataformas
18- El sistema debe permitir filtrar obras por país de origen
19- El sistema debe permitir filtrar obras por valoración más alta
20- El sistema debe permitir recomendar obras según la obra elegida del usuario 

📃 RESEÑAS 📃
21- El sistema debe permitir añadir una reseña a una obra
22- El sistema debe permitir eliminar una reseña de una obra
23- El sistema debe permitir modificar una reseña de una obra
24- El sistema debe permitir mostrar/listar reseñas de obras

📃 MODERACIÓN 📃
25- El sistema debe permitir al usuario denunciar un comentario ofensivo
26- El sistema debe permitir al admin suspender cuentas temporalmente
27- El sistema debe rechazar cualquier tipo de contenido que suba el usuario fuera de la temática
28- El sistema debe advertir al usuario no registrado sobre contenido sensible de obras

📃 VALORACIÓN 📃
29- El sistema debe permitir valorar una obra
30- El sistema debe permitir quitar una valoración de una obra

📃 COLECCIONES 📃
31- El sistema debe permitir crear colecciones de obras personalizadas
32- El sistema debe permitir eliminar colecciones de obras personalizadas
33- El sistema debe permitir modificar el nombre de la colección de obras
34- El sistema debe permitir añadir una obra a una colección del usuario
35- El sistema debe permitir eliminar una obra de la colección de guardados del usuario

📃 FOROS 📃
36- El sistema debe permitir crear un foro de discusión
37- El sistema debe permitir al admin modificar datos de un foro de discusión
38- El sistema debe permitir al admin eliminar un foro de discusión
39- El sistema debe permitir al usuario eliminar su foro de discusión
40- El sistema debe permitir al usuario eliminar su comentario de un foro de discusión
41- El sistema debe permitir al admin eliminar cualquier comentario en un foro de discusión
42- El sistema debe permitir visualizar todos los foros de discusión
43- El sistema debe permitir visualizar foros filtrado por título
44- El sistema debe permitir visualizar foros filtrado por palabras claves
45- El sistema debe permitir comentar en un foro de discusión
46- El sistema debe permitir dar like a un comentario de un foro de discusión 

📃 ARTÍCULOS 📃
47- El sistema debe permitir al admin crear artículos
48- El sistema debe permitir al admin eliminar un artículo
49- El sistema debe permitir al admin modificar un artículo 
50- El sistema debe notificar dentro del sistema a los usuarios registrados sobre artículos publicados 

📃 CONTACTO 📃
51- El sistema debe tener disponible medios de contactos para comunicarse con el creador de la página
52- El sistema debe tener disponible una sección sobre recomendaciones que el usuario quiera aportar
53- El sistema debe tener disponible una sección para donaciones que el usuario quiera realizar

--- REQUERIMIENTOS NO FUNCIONALES ---

1- El sistema debe tener interfaces de usuarios modernas
2- El sistema debe tener animaciones y efectos acorde al tema de la página
3- El sistema debe ser sencillo de utilizar
4- El sistema debe estar siempre disponible para el usuario
5- El sistema debe ser un diseño responsive disponible para cualquier dispositivo
6- El sistema debe tener seguridad para proteger las cuentas de los usuarios
7- El sistema debe tener una gestión segura de sesiones.
8- El sistema debe tener contraseñas cifradas.
9- El sistema deberá permitir incorporar nuevos tipos de obras sin modificar el diseño existente
10- Las búsquedas deberán responder en menos de 1.5 segundos.
11- El sistema debe ser compatible con todos los navegadores
